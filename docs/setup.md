# Setup Guide

## Enable console.log in CS2

1. Launch CS2
2. Open console (~ key)
3. Type: `con_logfile 1`
4. Press Enter

The log file will be at:
`Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\console.log`
