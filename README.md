# 🎮 Vexora — CS2 Macro Suite v2.2

Modern CS2 macro suite with **automatic bomb timer** and **key display overlay**.

![Version](https://img.shields.io/badge/version-2.2-blue)
![AHK](https://img.shields.io/badge/AutoHotkey-v2.0-green)

## ✨ Features

### Macros
- 🏃 **Bhop** — bunny hop with configurable rate
- 🔫 **Auto Pistol** — 50 CPS, pistol slot only
- 👁 **Fast Scope** — quick scope + weapon swap

### Overlays
- 💣 **Auto Bomb Timer** — automatic 40s countdown
- ⌨️ **Key Display** — WASD + mouse buttons visualization

### Customization
- 🎨 6 themes (Dark, Midnight, Purple, Emerald, Crimson, Frost)
- 🔧 Custom colors for overlays
- 💾 Auto-save all settings to `vexora_config.ini`
- 🖼 Adjustable opacity for all overlays

## 📥 Installation

1. Install [AutoHotkey v2.0](https://www.autohotkey.com/)
2. Download `Vexora.ahk`
3. Run the script
